# Crystal Miner Idle (Expanded)

## Новое
- 8 улучшений с постепенным открытием
- Система Prestige (+50% множитель за уровень)
- Интерактивный туториал (TutorialManager)
- Визуальные эффекты клика (CrystalClickEffect)

## Ассеты
1. Kenney UI Pack — https://kenney.nl/assets/ui-pack
2. Любые частицы/кристаллы из Kenney или OpenGameArt

## Сборка
1. 2D проект Unity 6000.6.9f1
2. Скопируй Assets
3. Tools → Setup Crystal Miner Idle
4. Назначь спрайты Kenney
5. На кристалл повесь CrystalClickEffect и ParticleSystem
6. Добавь TutorialManager на Canvas и свяжи текстовое поле
7. Play
